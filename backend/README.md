# Backend legado

Esta carpeta contiene una implementación anterior configurada para MySQL y no es la API que consume actualmente el frontend.

La API activa del proyecto está en `server/` y usa PostgreSQL. Sus instrucciones, variables de entorno y migraciones están en `server/README.md` y `server/database/migrations/`.

No uses los scripts de esta carpeta para iniciar el sistema actual. Se conserva por ahora para no borrar el trabajo previo mientras se termina la migración.
